## 来源

- 源图：`997fb16de13dbd8529b554242f5f572a.png`（单张压平，无分层、无表情列）
- 原尺寸：552×736；裁到角色外接框后 485×629

## 哪些是原画，哪些是补画

| 内容 | 来源 |
|---|---|
| 身体、毛色、背包、睡袋、四肢 | 原图（背景已抠掉） |
| 闭合眼 + 微笑（`idle` / `sleepy`） | **原图** |
| 睁眼（`eyes_open`） | **补画**：抹掉原闭合弧线，画深色眼球 + 两个高光 |
| 半闭（`eyes_half`） | **补画**：同上，上眼睑压住一半 |
| 嘴 微张 / 大张 / O 形 | **补画**：抹掉原微笑线，画口形 + 舌头 |
| 侧目 / 转身 / 走路 | **没有**：单张压平图做不到 |

## 已知限制

- 睁眼与口型是程序补画，风格接近但不等于原画；要更好请让美术出分层源图。
- 眼睛左右各一个部件（`eyes_open` / `eyes_open_r`），因为两只眼斑大小和倾角不同，不能共用。
- 没有独立腮红，`shy` 不可用。
- 没有侧面，`setPose("side")` 会被忽略。
